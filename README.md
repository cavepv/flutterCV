Flutter/Dart skills for job applications.

See [`cv_app/`](cv_app/) for the actual project, build/run instructions, and
architecture notes.

- 🍎 **iOS:** compiles and runs on iOS Simulator (CI-verified), see
  [`cv_app/README.md`](cv_app/README.md#ios) — no Apple Developer account,
  not tested on physical hardware
